# ROUNDS — Round Settings

BepInEx-мод для игры [ROUNDS](https://store.steampowered.com/app/1557740/ROUNDS/): меню для настройки количества раундов, очков и времени.

## Возможности
Меню открывается по **F8** (или кнопкой «Раунды» в левом верхнем углу):
- раундов до победы в матче (1–1000, по умолчанию 2);
- очков до победы в раунде (1–1000, по умолчанию 2);
- лимит времени на очко (выкл. или 5–300 с). По истечении умирает игрок с меньшим HP, при равенстве — случайный;
- карт (способностей) за выбор (1–100, по умолчанию 1): столько карт игрок берёт на старте и после каждого раунда;
- обновление предложенных карт (реролл) клавишей R: от 0 до 20 раз за выбор (по умолчанию 3);
- сколько карт показывается на выбор (2–9, по умолчанию 5);
- здоровье игроков (10–1000% от обычного, по умолчанию 100%);
- здоровье числами над игроком (текущее / максимум): в онлайне виден только свой, в локальной игре — оба; включается галочкой;
- карта «Похмелье от Хмеля»: +250% урона, +1000% разброса и стрельба на 23% медленнее, повышенный шанс выпадения (параметр `HmelDropPercent`, по умолчанию 7% на слот);
- свои шансы редкости карт: редкие/необычные в процентах, остальное — обычные (по умолчанию выключено — как в игре);
- выбор игровых локаций: галочка и список с отметками (кнопки «Все», «Никакие», «только» у каждой); карту выбирает хост;
- карта «Водичка от Dodomaks»: здоровье +200%, регенерация +3 HP/с, скорость передвижения −50%, повышенный шанс выпадения (`WaterDropPercent`, по умолчанию 7% на слот);
- тест-режим для игры в одиночку (Локально → Песочница, меню F8 → «Тест-режим»): запуск выбора карты как в раунде, выдача любой карты, отмена выбранных карт (последней или любой из списка), сброс всех карт, лечение;
- PIN-код на меню F8: задаётся в меню, до ввода PIN меню не открывается (хранится хэш; это защита от случайного доступа, а не от человека с доступом к файлам игры);
- пресеты: Стандарт, Быстро, Марафон.

**Мультиплеер:** настройки хоста передаются через свойства комнаты Photon; у клиентов меню только показывает значения. Мод нужен у всех игроков.

## Новые карты
В игру добавляются 46 новых карт (Дробовик, Берсерк, Стеклянная пушка, Тройной прыжок, Пулемёт, Черепаха и др.). Все они меняют обычные характеристики (урон, здоровье, скорость, пули, патроны, отскоки, вампиризм, прыжки); каталог — в `Cards.cs`. Отключаются параметром `CustomCards` (нужен перезапуск, должно совпадать у всех игроков). Названия и тексты карт проверены в игре; выбор карт в реальном матче пока не проверен.

## Установка
1. Установите BepInEx 5.4.23 (x64) в папку игры.
2. Положите `RoundsSettingsMod.dll` в `BepInEx/plugins/RoundsSettingsMod/`.
3. Запустите игру через Steam.

Настройки хранятся в `BepInEx/config/com.dmah.roundssettings.cfg`.

## Статус
Проверено в игре: загрузка мода, меню F8, кнопки и пресеты. Не проверено: поведение в матче (раунды/очки/таймер) и мультиплеер.

## Стабильность
Параметры «Карт за выбор» (>1) и реролл карт помечены как **экспериментальные** и по умолчанию включены (2 карты за выбор, 3 реролла): в онлайне они могут вызывать наложение карт; чтобы выключить — «Карт за выбор» = 1, реролл = 0. Остальное (раунды, очки, время, здоровье, число карт на выбор, новые карты) работает через обычный ход игры.
